# SynthKeep

**本地游戏库 · Windows 64 位**

把散落在各个平台、各个硬盘里的游戏收进一处：统一封面、统一分类、统一计时。所有资料都保存在程序旁边，**不联网上传，不需要注册账号**。

| | |
|---|---|
| 当前版本 | 5.0.0 |
| 适用系统 | 64 位 Windows 10 / 11 |
| 作者 | B 站 · 朝日骑士团 |

## 快速开始

1. 到 [Releases](https://github.com/takiyoru/SynthKeep/releases) 下载 `SynthKeep_v5.0.0_win64.zip`（约 30 MB）
2. **把整个压缩包解压** —— 不要只把 `SynthKeep.exe` 单独拷出来
3. 双击 `SynthKeep.exe`

启动时会遇到两个提示，都是正常的：

- **「Windows 已保护你的电脑」** → 点「更多信息」→「仍要运行」。没有购买签名证书的个人软件都会出现。
- **用户账户控制（UAC）** → 点「是」。程序需要这个权限才能读取游戏占用空间、设置开机启动。

**建议第一步**：点工具栏的「一键导入游戏」把电脑里已有的游戏扫进来。绝大多数人扫完就不需要手动添加了。

> 关掉窗口不等于退出。点 × 只是收进系统托盘，计时继续。双击托盘图标恢复窗口，右键托盘图标可「显示主界面 / 设置 / 退出程序」——只有点「退出程序」才真正结束。

## 把游戏收进来

### 一键导入

工具栏第二个按钮。程序自动找出本机游戏平台，列出装过的游戏，勾选后点「导入选中」，已导入的会自动跳过。

- **支持平台**：Steam、WeGame、Epic、Ubisoft Connect、EA，以及主流二次元手游的 PC 启动器
- **跨盘识别**：Steam 库分散在 D 盘、F 盘、移动硬盘都能找到，不用手动指路
- **只认游戏本体**：自动跳过启动器、运行库、卸载程序、补丁、壁纸和工具类软件——不会把 Wallpaper Engine 这类程序当游戏收进来
- **深层目录**：像 `游戏\bin\x64\游戏.exe` 这种结构，会自己挑出真正该启动的程序

### 手动添加

工具栏第一个按钮，选一个 `.exe`，然后按需填写：游戏名、封面（选图后右侧立即预览）、存档文件夹、所属文件夹、标签、是否管理员运行、是否日语环境运行。封面支持 PNG / JPG / WEBP / GIF。

### 扫描自己的文件夹

游戏没装在平台上、而是自己放在某个硬盘目录里，可以直接把那个目录加进来扫。每个子文件夹只挑出一个最像游戏本体的程序，不会把 config、uninst、vcredist 这类附带程序当成游戏。

### 自动补齐资料

工具栏「自动化管理」→ 选模式 → 开始分析 → 预览结果 → 应用。程序联网完成四件事：

| 补齐什么 | 补完之后 |
|---|---|
| 封面与原名 | 卡片不再是空白灰块；日文 / 英文原名一并保存，方便对照与搜索 |
| 简介与开发商 | 详情页能看到作品内容与制作方，也能按开发商自动分文件夹 |
| 社区评分 | 与你的个人评分并排显示，判断「大家都说好」还是「只有我喜欢」 |
| 标签 | 统一成中文标签并归入对应题材，标签统计栏随之可用 |

分析结果会**先给你看一遍**，每条都能取消勾选；已有封面不会被覆盖；找不到资料的标成「资料不足」并跳过，不会硬塞进某个分类。

### 自动分类

导入或分析时自动判断，之后可随时调整：

- **玩法**：galgame、二次元手游、单机游戏、网络游戏。平台游戏统一算单机；内置二次元手游资料，离线也能认出来。
- **题材**：射击、动作、竞速、角色扮演、策略、经营模拟、音乐、文字冒险。galgame 默认归文字冒险，真有战棋/养成/射击等玩法时才改判。

## 整理与查找

### 文件夹（最多三级）

「新建文件夹」可以在「全部游戏」里建一级，在一级里建二级，在二级里建三级，层级同步显示在左侧。没归进任何文件夹的游戏直接待在「全部游戏」里，**不会多出一个「未分组」**。

- 网格视图先看到文件夹，点进去才是游戏；工具栏「← 全部文件夹」退回上一层
- 文件夹封面默认用组内第一款有封面的游戏，也可以自己换
- 大小三档（小 / 中 / 大）；鼠标移到文件夹上点 ✎ 改名、点 × 删除
- 删文件夹不会删游戏，里面的游戏回到「全部游戏」

### 自动分组

| 用法 | 效果 |
|---|---|
| 在「全部游戏」上右键 → 新建分组 | 建一个一级文件夹，自己起名 |
| 在一级文件夹上右键 → 自动分组 | 按开发商自动建二级文件夹并归类。缺开发商信息的会跳过，先跑一次补资料 |
| 在二级文件夹上右键 → 自动分组 | 按标签自动建三级文件夹，是「视图」——同一游戏可同时出现在多个标签下，不会真的搬来搬去 |

### 标签

右侧「标签统计」栏按数量从多到少列出所有标签，点一下只看带这个标签的游戏，不受文件夹限制。**文件夹管位置，标签管属性，两套互不打架。**

### 批量整理

工具栏「选择」进入选择模式，可点卡片、勾选框，或「全选」当前筛选结果，然后：

- **分组管理**：一次把选中游戏改到某个一级 / 二级文件夹，或全部移出
- **标签管理**：新建标签、从现有标签勾选，模式可选「添加 / 删除 / 替换」；下方显示共同标签，点 × 立即移除
- **批量删除**：只删记录，硬盘文件保留

### 看图还是看表

网格视图只显示封面和名字，干净；列表视图把评分、标签、最后运行、总时长、占用空间、评论都摊开。每行放几张、每页放几页，按窗口大小自动算，拉宽窗口自动多放一列。

### 排序

右上角下拉可选：名称、占用空间、运行时长、最后运行、**社区评分**、**我的评分**。点旁边箭头切换升降序，默认「高分在前」。

- **社区评分** = 大众口碑（Bangumi 条目评分）
- **我的评分** = 你自己打的分

想找「口碑最好但我还没玩」用社区评分，想回看自己最爱的用我的评分。

### 游戏详情

点卡片弹出详情：封面、名字、我的评分与社区评分、开发商；简介、你写的评语、标签，以及「评价 / 编辑 / 删除 / 启动」。简介太长会在框内滚动，不会撑破版面。

## 启动与计时

点卡片下方或列表里的「启动」，程序自动开始计时，游戏退出后自动结算，累加到总时长和当天明细。

| 选项 | 说明 |
|---|---|
| 管理员身份运行 | 个别老游戏需要管理员权限，勾上即可 |
| 日语环境运行 | 日文原版游戏需要转区时勾上，自动调用 Locale Emulator 拉起，照常计时 |
| 存档按钮 | 填了存档文件夹的游戏，卡片上会多一个「存档」，一键打开目录 |

**默认普通权限是故意的**：这样 Magpie 这类画面拉伸 / 超分工具不需要管理员权限也能作用到游戏窗口。确实需要管理员的游戏会自动回退到高权限，不会卡住。可在「设置 → 启动权限」里关掉。

**计时不准怎么办**：通过第三方启动器间接拉起的游戏可能捕捉不到退出信号，在卡片上点「结束记录」手动结算即可。手游启动器一直挂着不影响计时——时长按真正在跑的游戏本体算。

**删除游戏**会先告诉你记录对应的目录，然后二选一：

- 仅删除记录（默认）：库里不再显示，硬盘文件完好
- 连同游戏文件夹一起删：需额外勾选确认并有红字警告。盘符根目录、Steam 公共库、系统目录一律拒绝执行，防止误删整块硬盘

## 统计

回答三个问题：有多少游戏、一共玩了多久、最近在玩什么。

- **四张总览卡**：游戏总数、累计时长、占用空间、正在运行
- **分时段时长**：今日、本周（周一起算）、本月、今年，实时计算
- **游戏统计表**：每款游戏的评价、各时段时长、累计时长、占用空间；点表头排序，再点换方向
- **时长排行**：条形图看谁玩得最多，可切日 / 周 / 月 / 年，显示相对上一期涨跌——红色上涨、绿色下降，新进榜标「新增」
- **评价与评论**：星形按钮打 0–10 分（保留一位小数）并写评语，评分直接显示在卡片上
- **导出**：一键生成文字版汇总（平均分、各游戏评分、标签、时长、评语）到数据目录的「评价汇总.txt」

> 占用空间按**整个游戏安装目录**算，不是只算 exe 所在的小文件夹，所以《赛博朋克 2077》《巫师 3》会显示真实的几十 GB。老数据可在「设置 → 数据管理 → 重新计算占用空间」一键修正。

## 本机配置

侧栏第一行，把电脑核心信息集中在一页，不用再装检测软件。

| 看什么 | 能看到什么 |
|---|---|
| 核心硬件 | CPU、显卡、内存（容量 + 单/双通道 + 频率）、主板与 BIOS、操作系统 |
| 磁盘 | 每个分区的容量与占用，并标注属于哪块物理硬盘 |
| 显示器 | 每台一张卡：型号、接在哪张显卡、分辨率与刷新率、尺寸、色深、色彩空间、HDR 支持 |
| 综合评分 | 0–100 分与档位（旗舰 / 次旗舰 / 高端 / 中端 / 低端） |

**分数怎么来的**：参考内置的主流 CPU / 显卡公开跑分自动匹配型号；点「重新跑分」可在本地跑约 3 秒轻量测试（处理器、内存、磁盘），实测权重更高；型号没收录就按核心数、显存、硬盘类型估算，不会空着。这个分数只适合横向对比，不是鲁大师分数，不必和别人的截图逐分较真。

**型号库更新**：「更新数据库」→「立即更新」，抓取最新型号与跑分约 10 秒。断网也不会出错，继续用内置数据；平时启动后后台自动检查，超过一天才更新一次。

硬件信息只在第一次进入时读取一次，之后走缓存，切换页面不会反复检测。想重新采集点「重新读取」，工具栏会显示数据是「缓存」还是「刚更新」。

## 外观与背景音乐

### 配色与背景

预设配色一键换风格，也可以单独调主色、辅助色、背景色和文字颜色。支持深色 / 浅色 / 跟随系统（随 Windows 日夜切换）。卡片透明度用滑块调，背景图选完右侧实时预览并可调节显示强度——图片存进数据目录，换电脑一起带走。

### 背景音乐

「颜色设定 / 背景图片」下方的「添加音乐…」支持多选本地歌曲（MP3 / WAV / OGG / M4A / AAC / FLAC）。**直接引用原文件，不复制一份占双倍空间**；文件被移动或删掉会标记为缺失，重新指回即可。

| 功能 | 说明 |
|---|---|
| 播放控制 | 固定在左侧栏底部：播放/暂停、上一首/下一首、拖动进度、音量、循环模式（三态，会记住） |
| 歌词 | 同目录 `.lrc` 自动关联；本地没有时联网尽力找，找不到安静跳过 |
| 桌面歌词 | 独立悬浮歌词条，可换颜色、字体、字号、透明度，可开描边，可显示原文 + 译文两行 |
| 播放记忆 | 记住上次听到哪首、第几秒，下次打开接着放 |
| 切歌淡入淡出 | 换歌时音量平滑过渡，不炸耳朵 |
| 游戏时自动闪避 | 从 SynthKeep 启动游戏时音乐自动变小，退出后恢复（默认关闭，在播放器设置里打开） |

窗口收窄到只剩图标时，侧栏仍保留播放与切歌按钮。

## 设置与数据

**常用设置**：开机自启动、启动权限（游戏是否默认普通权限）、运行环境（自动找到 Locale Emulator 并读取配置列表，也可手动指定）。

**数据管理**：

| 按钮 | 作用 |
|---|---|
| 导出数据 | 把游戏库、时长、评分、主题、封面打包成压缩包，用于备份或换电脑 |
| 导入 PotatoVN 数据包 | 直接选 PotatoVN 导出的压缩包，不用解压；游戏、时长、评分、封面、分组一起搬过来，导入前自动备份 |
| 导入 SynthKeep 数据包 | 恢复本程序导出的包，完整还原游戏库与统计 |
| 打开数据目录 | 直接跳到存放数据的位置，想手动复制备份就点这个 |
| 重新计算占用空间 | 游戏搬过目录、或早期数据算得不准时统一重算 |
| 恢复初始设置 | 清空全部个人数据，不可撤销，建议先导出备份 |

**数据放在哪**：程序目录里的 `SynthKeep_Data` 文件夹。不上传云端、不需要账号。备份就复制整个文件夹，想彻底重来就删掉它，下次打开自动重建。升级新版本时旧数据自动兼容，游戏和分组不会丢。

**换电脑**：把整个程序文件夹（含 `SynthKeep_Data`）拷过去直接能用；游戏路径变了的逐个改一下启动程序即可。也可以在新机器上先跑一次程序，再用「导入 SynthKeep 数据包」恢复。

## 常见问题

### 双击完全没反应、打不开

先确认两件事：**整个文件夹都解压了**（不要只把 exe 拷出来），**Windows 是 64 位**。

都没问题还打不开，就在程序目录运行 `SynthKeepCheck.exe`——它逐项检查系统、运行组件、文件完整性和启动过程，在桌面生成报告。把报告发给作者即可定位。

如果连这个检测工具都打不开，运行 `SynthKeepCheck.bat`——纯系统脚本，不需要任何运行组件，几乎不可能跑不起来，同样会在桌面生成报告。

最常见的原因只有一个：**缺少 Microsoft Edge WebView2 运行时**。Win11 一般自带，Win10 卸载过 Edge 或用精简版系统就会缺失。遇到时程序会直接弹窗提示，按提示装一次即可，装完不用重启。

### 其他

| 问题 | 处理 |
|---|---|
| 提示已在运行 | 它已经在后台或托盘里，双击任务栏 / 托盘图标即可。只有托盘右键「退出程序」才真正结束 |
| 杀毒软件报毒 | 个人开发、无签名证书的程序常被误报，加信任或白名单即可。程序不需要联网账号，也不改系统文件 |
| 自动补资料失败 / 没封面 | 这步需要联网，部分资料站需要代理。开着代理（含加速器）再试，程序会自己找可用端口 |
| 有的游戏没被识别 | 个别目录结构和工具软件很像会被保守跳过，用「手动添加游戏」指定主程序即可 |
| 桌面歌词没出现 / 关不掉 | 先在设置里确认开关是开的；被全屏程序挡住也会看不到。点浮窗 × 一次即可关闭，之后从播放器设置重新打开 |
| 时长没有记录 | 第三方启动器间接启动的可能捕捉不到退出，点卡片「结束记录」手动结算；也确认程序没被任务管理器强制结束 |
| 能装在 U 盘吗 | 可以，程序与数据在同一文件夹，整个拷走就能用。但时长按本机记录保存，换机器不会合并 |
