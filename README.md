# SynthKeep

一款本地游戏库管理工具，适用于 Windows 10/11（64 位）。所有数据保存在程序所在文件夹，不联网上传。

## 下载与安装

1. 在右侧 **Releases** 下载 `SynthKeep_v5.0.0_win64.zip`
2. **把整个压缩包解压** —— 不要只把 exe 单独拷出来
3. 双击 `SynthKeep.exe` 运行（首次会弹用户账户控制，点「是」）

打不开时用同目录的 `SynthKeepCheck.exe` 或 `SynthKeepCheck.bat` 检测，把生成的诊断报告发给作者。

## 主要功能

- **游戏库**：一键导入 Steam 游戏，也可手动添加任意 exe；自动补充封面、原名、简介与评分；社区评分 / 我的评分两种排序口径
- **整理**：三级文件夹分组、标签、搜索、多种排序与批量整理
- **启动与计时**：记录运行时间、按时间段统计、时长排行、导出
- **背景音乐**：本地音乐文件夹导入、歌词与翻译匹配、桌面悬浮歌词、播放记忆、音量闪避
- **外观**：多种配色方案、背景图、透明度调节
- **数据**：导入导出、自定义数据位置，换电脑只需拷贝程序文件夹

完整功能说明见发布包内的 `使用说明.pdf`。
